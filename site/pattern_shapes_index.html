四、口径与缺口

  • 标签含义（分类器 v1.3 实际会输出的 16 个）：A1 V型极值反转 / A2 中位U型反转 / A3 折价修复 / A4 下狗整场反转 / A5 W型双底 / A6 反弹确认 / A7 强强对话错杀 / B1 尾盘崩塌 / B2 死亡螺旋 / B3 假反弹后归零 / B4 直线阴跌 / B4 低开阴跌 / C1 中位震荡 / C2 五五开开局碾压 / C2 早期缩距·热门确立 / 热门全程压制。 C3 中位震荡后突破：形态手册（REVERSAL_PATTERN_LIBRARY.md）中有定义，但分类器尚未实现，当前不会输出（不应计入形态种类数）。
  • 比赛内窗口（2026-10-18 起）：所有形态统计只使用开赛到结算之间的价格段。起点 = 价格离开赛前基线后的第一段持续移动（向前保留约 3 分钟），终点 = 首次进入结算平台（≈100c / ≈0c）；第二局起以前一局结算后为下限，图间停滞不计入。旧的全窗口（含赛前 ~24-36h 与赛后平台）数据完整备份在 reports/archive/pattern_backup_2026-10-18/，新旧口径不可直接混算。
  • 粒度（两档口径，勿混算）：600s = 未回填/仅拿到 10 分钟采样的市场（一个小局/地图约 45 分钟 = 4-6 个点，标签只作方向参考）；60s = 用 startTs/endTs + fidelity=1（不传 interval）回溯的分钟级序列。2026-10-18 起一级赛事已全量回填 60s（LoL 231/231、CS2 62/62）。
  • 分钟级可回溯（2026-10-18 修正）：此前“超过 24 小时只能拿 600s”是旧工具固定传 interval=1d 导致的误判；不传 interval 时，2 个月前的老比赛仍可返回 60s（实测 7 天窗口 9981 点）。归档工具 tools/backfill_minute_snapshots.py（只写 .hires，不覆盖原 600s）。
  • 结果：以 Polymarket 结算价定胜负；比分由逐局归属统计，决胜局无独立市场时按整场结算归属补足（条目里注明）。
  • 游戏不混算：LoL 与 CS2 的赛制、地图/小局结构、盘口深度都不同；本页所有频次、深水比例、让一追二与抄底回测均按游戏分开，禁止合并成一个结论。
  • CS2 结构差异：Polymarket 的 CS2 BO3 只开 Map 1 / Map 2 胜者盘（Map 3 只有 Rounds 盘），决胜图按整场归属补足，已在 result 标注。
  • 赛事分级（2026-10-15 起）：本库只收一级（关键）赛事—— 一级 = LCK/LPL/LEC/LCP/LCS/KeSPA/德杯/国际赛；CS2 的 ESL Pro League/IEM/BLAST/EWC/Thunderpick 正赛。 EMEA Masters、小区域联赛、资格赛/升降级赛已按用户指令剔除（LoL −276 场、CS2 −7 场）， 原始快照与旧全分级 JSON 仍留档、不参与出数。
    分级口径：config/esports_tiers.json · 判定 tools/esports_tier.py · 回归 tests/test_esports_tier.py · 见 形态分级体系 与 形态速查。
  • 尚未采集：CS2 三级赛事（ESEA / CCT / Dust2.dk / United21 等）按已定口径不纳入；Thunderpick 正赛已并入一级口径（10-14 两场），PGL / Thunderpick 资格赛（约 56 场事件）待定；10-15 之后的比赛待赛后回补。

## 3. 预测口径

### 3.1 训练样本

读取一级联赛 LoL / CS2 的形态报告，使用其中逐小局与整场的 1 分钟 / 10 分钟价格轨迹。每个历史轨迹拆成多个观察点，记录：

- 观察点之前可见的价格特征：现价、起点、区间高低、回撤、反弹、斜率、穿越次数、进度；
- 观察点之后才发生的结局：最终形态标签、是否获胜、未来低点与高点；
- 同一场比赛、同一市场层级、同一游戏才可进入近邻池。

赛前及赛后平台期不进入形态学习；“回放观察点”只展示截至观察点可见的数据。

### 3.2 相似度

对当前观察点计算特征，在同一游戏与市场层级内按特征距离取前 50 个历史观察点，再按距离加权。输出三个候选形态：

- `相似样本权重`：该形态在近邻池中的权重占比，不是胜率；
- `历史方向率`：候选方向在历史相似样本中的兑现比例；
- `样本数`：低于门槛时显示“样本不足”，不输出强弱结论。

### 3.3 决策卡

每张候选卡给出：

1. 方向倾向；
2. 条件买入区间；
3. 两档止盈参考；
4. 条件失效位；
5. 对应的形态解释与反转证据。

所有数字均来自历史相似样本的分位统计，仅作为交易纪律参考，不构成投资建议。

### 3.4 校准与防止重复计权

- 同一场比赛的多个观察点先归并成一张比赛票，历史方向率按去重比赛数计算。
- 方向率使用 Beta(2,2) 平滑；少于 8 场去重样本时只显示“样本不足”。
- 买入区围绕现价与未来低点分位收紧，最多约 10c；卡片区分“现价附近 / 回踩区 / 等待回踩”。
- 止盈同时显示历史触达率，避免把单一 97c/100c 终点当作确定性目标。

## 4. 产品边界

- 不把“相似度”写成“准确率”。
- 不在开赛前没有价格轨迹时伪造买卖点；只显示赛前先验或等待有效观察点。
- 不跨 LoL / CS2 借用样本，不把逐局与整场混算。
- 不把 10 分钟级数据冒充 1 分钟级；页面始终展示路径粒度。
- 不自动下单，不主动平仓。

# 赔率形态结构库（结构化统计 · 全量）

最后更新：2026-10-18（**形态统计改为仅比赛内窗口**：赛前长平台 / 赛后结算平台 / 图间停滞全部剔除；
旧全窗口数据完整备份；LoL 与 CS2 的样本、统计、页面全部分开，不再混算）

定位：这是**形态层的统计库**——回答"这么多场、这么多个小局/整局市场里，价格到底长成什么形状、
各形状占比多少、按形状买进去的期望值是多少"。
逐形态的图形特征/正例/反例/仓位纪律见 `docs/framework/REVERSAL_PATTERN_LIBRARY.md`（形态手册，2026-08-18）；
本文只做**可复现的批量统计**，两者是同一套标签体系（`tools/classify_pattern.py`）的不同切面。

机器库：`docs/data/intel/price_paths.json`（每条 slug 一条，含 `price_shape` 串；
2026-10-15 起带 `granularity` 字段——当前 **378/474 条**有机器判定粒度（60s 13 / 600s 365），
其余 96 条为复盘文档来源的人工条目、粒度未标注，**不要默认按 600s 解读**）。
页面：`reports/pattern_shapes_index.html`（总览）→ 分区间明细页；
粒度对照（1 分钟级 vs 10 分钟级，样本量/形态覆盖/结论来源分层）：`reports/pattern_shapes_granularity.html`。
**统一入口（推荐）**：`reports/pattern_library.html` —— 一个页面内嵌总览 / 粒度 / 分类 / 速查 / 曲线图，
左侧导航切换，不再需要同时打开多个 HTML。
**曲线图页（看形状本身）**：`reports/pattern_charts_<批次>.html` —— 每场比赛 = 一张卡片，
内含"整局 + 每个小局/地图"的小图，每张图两条线 = 两支队伍的赔率（50c 虚线为领先权分界，
两线交叉即翻转），图下标注形态标签、低→高、终点、原始点数与粒度；支持按 60s / 600s 筛选。
生成工具 tools/build_pattern_charts.py（绘图降采样，统计仍用全量序列）。

## 一、口径（读数字之前必须先看）

```text
0. 比赛内窗口（2026-10-18 起，最高优先级）：
   所有形态、深水比例、让一追二、抄底回测**只使用开赛到结算之间的价格段**。
   - 起点：价格离开赛前基线后的第一段持续移动（向前保留约 3 分钟）；
   - 终点：首次进入结算平台（>=0.985 或 <=0.015，允许结算后的 0.98 小幅抖动）；
   - 第二局起：以前一局结算终点 + 1 分钟为下限，图与图之间的停滞不计入下一局；
   - 数据自身推断优先：历史 gamma 的 game_start 有时区/小时级偏移，元数据只在
     落入"结算前 7 小时内"这一合理区间时才作为辅助；否则标记 `window=inferred`；
   - 单场最长按 7 小时兜底（BO5 + 暂停），超过即截断，避免把赛前长平台重新带进来。
   旧口径（含赛前 ~24-36h 与赛后平台）已完整备份在
   `reports/archive/pattern_backup_2026-10-18/`（含 SHA256SUMS.txt），
   **旧统计与新统计不可直接混算**；需要对照时用 `--full-window` 重新生成旧口径。
   LoL 与 CS2 的窗口、样本、频次、回测一律分开：两个游戏的赛制与盘口结构不同，
   禁止合并成一个结论。
1. 粒度：**1 分钟可回溯，不限于赛后 24 小时**（2026-10-18 修正，推翻 10-15 的误判）。
   a) 正确用法：`/prices-history?market=<TOKEN>&startTs=..&endTs=..&fidelity=1`
      —— **不要传 `interval`**。实测 2026-08-16 的老比赛在 12h 窗口返回 625 点/侧、
      中位 **60s**；24h 窗口 1345 点；7 天窗口 9981 点（跨度 166.4h）。
      60s 与 10min 序列在 63 个重叠时间戳上最大价差 **0.0000**。
   b) 错误用法：带 `interval=1d&fidelity=1` 会进入服务端聚合路径，老比赛返回 0 点；
      `interval=max&fidelity=1` 只给 1 点；`interval=max&fidelity=10` 才是 600s。
      10-15 的“分钟级只能 24 小时内归档”结论，根因是旧工具固定传了 `interval`。
   c) LoL / CS2 / Dota2 都已实测可回溯（Dota2 老比赛 492 点 / 60s / 8.2h）。
      1 分钟点是**采样价格**，不是订单簿；无成交分钟可能沿用前值。
   d) 归档仍建议赛后尽快做，但“过期不可回溯”不再成立；批量回填见
      `tools/backfill_minute_snapshots.py`（只写 `.hires.jsonl`，不覆盖原 600s 数据）。
   e) **展示平滑（2026-10-18 起）**：曲线分三层——`raw` 原始观测 / `filled` 仅补
      ≤3 倍中位间隔的小缺口 / `display` 平滑展示线（3 点中值 + EMA 0.45）。
      600s 路径不做分钟级插值，保持原始折线并标 `低置信度`；
      形态分类、频次、深水、回测一律仍用 `raw`，平滑只影响看图。
      图下标注“原始点数 / 插值比例 / 置信度”，低置信度不得当精确拐点使用。
   粒度以条目字段 `granularity`（`60s` / `600s` / `mixed`）为**唯一权威**，
   且**按实际采样间隔判定、不看文件名**：赛后不久抓取的普通序列
   （`interval=1d&fidelity=1`）本身就是 60s，并不等于"只有 `.hires.jsonl` 才是 60s"
   （2026-10-15 修正：曾按文件名把 10 场真实 60s 场次错算进 600s 组）。
   （2026-10-18 起正在把一级赛事批量回填为 60s；回填完成后本段分布需重算，
   以各 section JSON 的 `granularity` 字段为准。）
   影响：① 600s 条目的小局形态只作方向参考，不认精确拐点；
        ② "首次触及 X 价" 的成交价往往已经低于真实最低点 => 抄底类回测偏保守；
        ③ 60s 条目可以把 A1/A6（快速 V 型）从"被采样吃掉"里救回来；
        ④ 60s 与 600s 都只算比赛内窗口；但 60s 的**归档起点可能略晚于开赛**，
           所以两档的 n / ROI 差异仍同时来自「精度 + 起点 + 选择性偏差」
           （60s 只覆盖能及时归档的少量场次），**两档不得互相推证**；
        ⑤ 跨条目比较前先看粒度，别把粒度差异当成形态差异。
2. 结果仲裁：Polymarket 结算价（小局 >=0.9 判胜）。
   比分由逐局归属统计；决胜局无独立市场/无成交时按整场结算归属补足（条目里注明）。
3. 一侧 vs 两侧：每个市场有 2 个 outcome token。统计里"胜方侧/负方侧"分开算；
   负方侧 84% 是 B4 直线阴跌（输家代币自然衰减），这是恒等式的产物，不是规律。
4. 形态可多标签：一个走势可以同时命中 A2 + A5 等，所以频次相加 > 100%。
5. 未结算/无整场定价的场次不入库（形态再好也没有结果锚点）。
```

## 一·补、形态分级体系：一共有多少种形态、该怎么分层（2026-10-15 定）

页面：`reports/pattern_taxonomy.html`（工具 `tools/build_pattern_taxonomy_page.py`）。

**分几层（哪层必须拆、哪层拆不动）**

```text
第 1 层 游戏  LoL / CS2       —— 必须拆。CS2 是地图制（BO3 常只开 Map1/Map2 胜者盘，
                                 第三图只有 Rounds 盘，决胜图按整场结算补足），
                                 LoL 是标准小局制、逐局盘更全；两者"整局被砸后回弹"的
                                 机制不同，混算会把赛制差异读成形态差异。
第 2 层 范围  整局 / 逐局        —— 必须拆。分布完全不同：整局由 A3 折价修复 + 热门压制 +
                                 A2 中位 U 型主导；逐局由 C2 五五开开局碾压主导
                                 （LoL 逐局 298/569 ≈ 52%）。
第 3 层 侧    胜方侧 / 负方侧     —— 分开统计，负方侧只作对照。B 类（B1/B2/B3/B4 直线/B4 低开）
                                 几乎只出现在负方侧，是输家代币归零的恒等式产物。
第 4 层 粒度  60s / 600s       —— **暂不拆**，只能当格内"数据质量档"。四个主格里 60s 只有
                                 1 / 4 / 12 / 24 例，单独成表每格形态样本会掉到个位数。
                                 等 60s 每格累积到 ≈ 20 例以上再升格为独立维度。
不拆    联赛  LCK/LPL/LEC/次级   —— 影响的是"实力差"先验，属策略层筛选参数，不进形态分类维度。
=> 有效主格 = 2 游戏 × 2 范围 = 4 格；粒度与侧作为格内质量/统计维度。
```

